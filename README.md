Spectro Cloud provides Palette, an enterprise platform for managing the full lifecycle of Kubernetes clusters and cloud-native and AI infrastructure across data centers, public clouds, bare metal, and the edge. Palette uses declarative cluster profiles (packs, Helm charts, manifests) for repeatable deployments, unified VM, container, and AI-workload management, and granular governance across distributed and air-gapped environments. Palette VerteX adds FIPS 140 and FedRAMP posture for regulated and public-sector organizations. The Palette API is a large REST surface (1,200+ operations) covering clusters, cluster profiles, cloud accounts, projects, tenants, registries, and edge hosts, with Go/TypeScript SDKs, a Terraform provider, a Crossplane provider, and the Palette CLI for automation.

**Areas:** Company · Infrastructure · Kubernetes · Cloud-Native · Cluster Management · Edge Computing · Multi-Cloud · DevOps · AI Infrastructure

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Spectro Cloud: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
